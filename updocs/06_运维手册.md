# 06 运维手册

> **零配置可运行**：默认参数已适配大多数场景。

## 一、环境变量

### 1.1 归档器（Standalone）

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `WQ_ARCHIVER_FLUSH_SEC` | 1.0 | 归档轮询间隔（秒） |
| `WQ_ARCHIVER_VACUUM_HOURS` | 24 | SQLite VACUUM 间隔（小时） |
| `MING_TRIAGE_INTERVAL_SEC` | 1800 | 分诊周期（秒） |

### 1.2 归档器（Cluster）

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `WQ_DB_HOST` | — | MySQL 主机 |
| `WQ_DB_PORT` | 3306 | MySQL 端口 |
| `WQ_DB_USER` | root | MySQL 用户 |
| `WQ_DB_NAME` | ming | MySQL 数据库名 |
| `WQ_PROJECT_ID` | default | 项目 ID |

### 1.3 通用配置

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `MING_MODE` | standalone | 运行模式 |
| `MING_HOT_DIR` | ~/.ming/hot | 热轨目录 |
| `MING_OTEL_PORT` | 4319 | OTEL 接收器端口 |

## 二、凭据保险库（v0.11.8）

MySQL 密码和土行孙推送 Token 统一由 `credential_vault.py` 管理。

| 凭据 key | 环境变量 | 用途 |
|----------|----------|------|
| `mysql.password` | `MING_SECRET_MYSQL_PASSWORD` | MySQL 连接密码 |
| `tusunsun.pushToken` | `MING_SECRET_TUSUNSUN_PUSHTOKEN` | P0 推送认证令牌 |

**设置方式（二选一）**：

```bash
# 方式 1：环境变量
export MING_SECRET_MYSQL_PASSWORD="your_password"

# 方式 2：~/.ming/.secrets 文件（推荐）
echo "mysql.password=your_password" >> ~/.ming/.secrets
chmod 600 ~/.ming/.secrets
```

## 三、部署指南

### 3.1 Standalone 模式

```bash
# PyPI 安装用户：
python3 -m src.ming start

# 源码用户：
MING_MODE=standalone python3 src/ming.py start
```

> **命令说明**：`ming` CLI（`ming dx list` 等）是诊断查询入口，
> 服务管理（启动/停止归档器）使用 `python3 -m src.ming`。

### 3.2 Cluster 模式

```bash
# Docker MySQL 快速启动
docker-compose up -d mysql

# 启动归档器
MING_MODE=cluster \
WQ_DB_HOST=127.0.0.1 \
WQ_DB_PORT=3306 \
WQ_DB_USER=root \
WQ_DB_NAME=ming \
python3 -m src.ming start
```

### 3.3 systemd 开机自启

项目提供 systemd unit 模板文件，位于 `contrib/systemd/`：

| 文件 | 用途 |
|------|------|
| `ming-archiver.service` | 归档器守护进程 |
| `ming-web.service` | Web 面板（需要先启动归档器） |
| `ming-opencode.service` | OpenCode 探针守护进程 |

**安装方法**（user 级别，无需 sudo）：

```bash
# 1. 创建 user systemd 目录
mkdir -p ~/.config/systemd/user

# 2. 拷贝模板并按需修改 ExecStart 路径
cp contrib/systemd/ming-archiver.service ~/.config/systemd/user/
cp contrib/systemd/ming-web.service ~/.config/systemd/user/
cp contrib/systemd/ming-opencode.service ~/.config/systemd/user/

# 3. 启用并启动
systemctl --user daemon-reload
systemctl --user enable --now ming-archiver ming-web ming-opencode

# 4. 允许用户服务在未登录时运行（可选）
sudo loginctl enable-linger $USER
```

**一键安装 OpenCode 探针**（仅探针）：

```bash
ming service install    # 自动创建 ~/.config/systemd/user/ming-opencode.service
```

> `ming service install` 只安装探针服务。归档器和 Web 面板请使用上述模板。

### 3.4 OpenClaw 集成

```bash
# 1. 安装探针插件
cp -r extensions/openclaw ~/.openclaw/extensions/mingjing-probe
openclaw config set plugins.entries.mingjing-probe.enabled true

# 2. 启动归档器 + Web 面板
python3 -m src.ming start
ming web serve

# 3. 开机自启（推荐）
# 使用 contrib/systemd/ 模板，或手动启动上述命令
```

## 四、监控指标

### 4.1 归档器健康

```bash
ming health
ming self-check
cat ~/.ming/.archiver_heartbeat  # 时间戳应接近当前
```

```bash

ls -lh ~/.ming/ming.db   # SQLite 大小
```

## 五、故障排查

| 问题 | 检查方法 |
|------|----------|
| 归档器未运行 | `cat ~/.ming/.archiver_heartbeat` |
| 热轨无文件 | `ls ~/.ming/hot/`（需先触发 Agent 会话） |
| Web 面板无数据 | `curl http://localhost:18088/api/data.json` |
| 探针未启用 | `openclaw config get plugins.entries.mingjing-probe.enabled` |
| Gateway 启动后无事件 | 等日志出现 `[mingjing-probe] Probe runtime started`（2-4 分钟懒加载） |

## 六、场景推荐配置

```bash
# 场景 1: 默认（1000 events/s）
MING_MODE=standalone python3 -m src.ming start

# 场景 2: 高吞吐（5000 events/s）
WQ_ARCHIVER_FLUSH_SEC=0.5 \
MING_MODE=standalone python3 -m src.ming start

# 场景 3: 省电模式（200 events/s）
WQ_ARCHIVER_FLUSH_SEC=5.0 \
MING_MODE=standalone python3 -m src.ming start
```

## 七、备份与恢复

### 7.1 备份

```bash
# 归档器自动备份（每日）
ls ~/.ming/ming.db.bak

# 手动备份
cp ~/.ming/ming.db ~/.ming/ming.db.manual.bak
```

### 7.2 恢复

```bash
# 停止归档器
python3 -m src.ming stop

# 恢复数据库
cp ~/.ming/ming.db.bak ~/.ming/ming.db

# 重启归档器
python3 -m src.ming start
```
