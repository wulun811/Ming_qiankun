# 快速上手 — 乾坤镜 Mingjing

> 5 分钟体验完整链路：发射事件 → 归档 → 诊断 → Web 目镜

## 1. 克隆

```bash
git clone https://github.com/wulun811/Ming_qiankun.git
cd Ming_qiankun
```

## 2. 运行归档器（零依赖）

Standalone 模式仅需 Python 标准库，零第三方依赖：

```bash
MING_MODE=standalone python src/ming.py start
```

首次运行会自动创建 `~/.ming/` 工作目录和 SQLite 数据库。看到 `归档器已启动` 即成功。

## 3. 发射测试事件

打开另一个终端，确保在项目根目录：

```bash
python -c "
import sys; sys.path.insert(0, 'src')
from probe_uni import ProbeUni
p = ProbeUni(system='demo', mode='white')
p.emit('llm_invoke', {
    'layer_agent': {'step_id': 'test', 'session_id': 's1'},
    'layer_llm': {'model': 'gpt-4', 'input_tokens': 100},
    'layer_network': {'target_host': 'api.openai.com'}
})
print('Event emitted!')
"
```

## 4. 查看诊断

```bash
python src/cli.py dx list
```

会看到刚才发射的事件经过诊断引擎打分后生成的诊断结果。

## 5. 打开 Web 目镜

```bash
python src/ming.py web serve
```

浏览器访问 http://localhost:18088 即可看到 Web 面板，包含事件流、诊断卡片、系统健康面板。

## 常见问题

**Q: `python src/ming.py start` 没反应？**
A: 检查是否在项目根目录执行，`src/ming.py` 是相对路径。

**Q: ImportError: No module named 'probe_uni'？**
A: 确保在项目根目录运行，`sys.path.insert(0, 'src')` 依赖当前工作目录。

**Q: Web 面板打不开？**
A: 先确认归档器已启动（`python src/ming.py status`），Web 面板需要归档器提供数据。

**Q: 如何停止？**
```bash
python src/ming.py stop
```

**Q: 如何查看两个入口的区别？**
- `src/ming.py` — 服务管理：start/stop/status/restart/web/service
- `src/cli.py` — 诊断查询：dx list/health/query/report

运行 `python src/cli.py --help` 查看所有诊断命令。
