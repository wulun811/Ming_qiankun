## 一、CLI 命令

### 1.1 常用命令

| 命令 | 说明 |
|------|------|
| `ming report` | 4 级健康报告（危急/警告/亚健康/健康） |
| `ming dx list` | 列出诊断记录 |
| `ming dx show <id>` | 显示诊断详情 |
| `ming health` | 归档器自身健康 |
| `ming status` | 系统状态 |
| `ming self-check` | 自检（探针/归档器/数据库/磁盘） |
| `ming triage run` | 手动触发分诊 |
| `ming web serve` | 启动 HTTP 服务（端口 18088） |

### 1.2 疾病操作命令

| 命令 | 说明 |
|------|------|
| `ming ignore <fault_id> -s <system>` | 忽略本次某系统的某疾病 |
| `ming archive-disease <fault_id> -s <system>` | 永久归档（不计入健康） |
| `ming restore <fault_id> -s <system>` | 取消忽略/归档 |
| `ming reset <system>` | 强制标记系统健康 |
| `ming reset-status` | 查看复位状态 |
| `ming instance-list` | 列出所有注册实例 |

### 1.3 运维命令

| 命令 | 说明 |
|------|------|
| `ming config` | 显示当前配置 |
| `ming archive list` | 列出冷轨文件 |
| `ming archive verify` | 证据链验真 |
| `ming skill list` | 列出已安装插件 |
| `ming query <sql>` | 原始 SQL 查询 |

## 二、Web Dashboard API

### 2.1 核心端点

| 端点 | 说明 |
|------|------|
| `GET /api/data.json` | 返回完整 data.json（27 个顶层字段） |
| `GET /api/events?limit=N&since=T&system=X` | 返回最新 N 条事件 |
| `GET /api/models` | 返回所有 distinct model 列表 |
| `GET /api/config` | 返回归档器配置（只读） |
| `GET /api/version` | 返回前端版本 |

### 2.2 统一查询入口（v0.11.9-alpha 新增）

`GET /api/query?name=X&params=...`

| 查询名 | 说明 |
|--------|------|
| `token-breakdown` | Token 消耗分解（按 model/hour/agent） |
| `tool-dangerous` | 危险工具调用审计 |
| `step-sequence` | Step 序列回放 |
| `step-loop` | Step 循环检测 |
| `memory-retrieve` | 记忆检索记录 |
| `agent-status` | Agent 在线状态 |
| `event-timeline` | 事件时间线 |

### 2.3 快捷端点

| 端点 | 等价于 |
|------|--------|
| `GET /api/token/breakdown` | `/api/query?name=token-breakdown` |
| `GET /api/tool/audit` | `/api/query?name=tool-dangerous` |
| `GET /api/agent/status` | `/api/query?name=agent-status` |

### 2.4 乾坤镜自检端点

| 端点 | 说明 |
|------|------|
| `GET /ming/health` | 自检（心跳/内存/归档延迟/容量） |
| `GET /ming/diagnoses?system=X` | 指定系统诊断列表 |
| `GET /ming/coverage?system=X` | 分诊覆盖率 |
| `GET /ming/tokens?system=X` | Token 用量/延迟/频率 |
| `GET /ming/integrity?system=X` | 哈希链完整性 |
| `POST /ming/push` | P0 诊断推送接收（需 X-Ming-Token） |

## 四、插件契约

### 4.1 插件注册

通过 `~/.ming/plugins/*/*.skill.yaml` 文件定义：

| 字段 | 说明 |
|------|------|
| `name` | 插件名称 |
| `version` | 版本号 |
| `type` | diagnostic/frontend/cron |
| `install.entrypoint` | 入口脚本 |

### 4.2 已注册插件

| 插件 | 类型 | 契约要点 |
|------|------|----------|
| lit_lite | diagnostic | 输入: SQLite 只读; 输出: JSONL; 隔离: 子进程 60s 超时 |
| web_dashboard | frontend | HTTP 服务 + data.json 导出 |
| tusunsun | cron | 土行孙专属诊断规则 |

### 4.3 插件执行

`plugin_runner.py` 扫描 YAML 文件，通过 `subprocess.run(timeout=60)` 子进程隔离执行。

> **插件崩溃不影响底座**。
