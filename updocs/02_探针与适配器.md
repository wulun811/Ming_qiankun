# 02 探针与适配器

> **探针纯粹**：只写 JSONL，不 import sqlite3/pymysql

---

## 一、探针系统

### 1.1 探针模式

| 模式 | 说明 | 完整性评分 |
|------|------|------------|
| `white` | 完整 payload，所有字段可见 | 1.0 |
| `black` | 脱敏 payload（仅允许字段） | 0.6 |

### 1.2 探针方法

| 方法 | 用途 |
|------|------|
| `emit(event_type, payload)` | 批量写入热轨 |
| `expect(event_type, within_seconds)` | 声明预期事件 |
| `fulfill(event_type)` | 标记预期事件已完成 |
| `touch()` | 心跳 |
| `health()` | 发送健康指标 |

### 1.3 事件类型

| 类别 | 事件类型 |
|------|----------|
| **元数据** | `__register__`, `__touch__`, `__detach__`, `__expect__`, `__fulfill__`, `__health__`, `__chain_reboot__` |
| **核心业务** | `llm_invoke`, `tool_call`, `memory_retrieve`, `agent_step`, `error` |
| **看门狗合成** | `system_crash`, `silent_anomaly`, `io_anomaly` |
| **平台** | `platform_snapshot` |

### 1.4 必填 Payload 层级

| 事件类型 | 必填层级 |
|----------|----------|
| `llm_invoke` | `layer_agent`, `layer_llm`, `layer_network` |
| `tool_call` | `layer_agent`, `layer_tool`, `layer_network` |
| `memory_retrieve` | `layer_agent`, `layer_memory` |
| `agent_step` | `layer_agent` |
| `error` | `layer_agent` |

> 缺失层级会标记 `_incomplete` 和 `_integrity_hint: "partial"`。

### 1.5 探针特性

| 特性 | 说明 |
|------|------|
| **批量写入** | 默认 10 事件/批，200ms 刷新间隔 |
| **Lamport 时钟** | 多进程共享文件，保证单调递增 |
| **文件锁** | Linux: fcntl，Windows: msvcrt |
| **磁盘保护** | 磁盘 <500MB 时自动拒绝写入 |
| **降级目录** | 热轨不可用时降级到 TEMP/ming_fallback |

## 三、适配器设计模式

### 3.1 方式 A：猴子补丁（9 个适配器）

运行时方法替换，包裹事件发射。目标类不存在时零影响。

**适用**：LangChain、LlamaIndex、CrewAI、OpenHands、AutoGPT、LIT、Vercel。

### 3.2 方式 B：插件钩子（3 个适配器）

通过框架官方 API 注册回调，零侵入。

**适用**：
- OpenClaw：`globalThis.openclaw.hooks`
- Hermes：`ctx.register_hook()`
- 土行孙：`core.on()` EventEmitter

### 3.3 方式 C：包装器+轮询（3 个适配器）

以子进程启动目标，通过 DB/文件系统采集，不修改目标进程。

**适用**：OpenCode wrapper（SQLite 轮询）。

## 四、各适配器诊断上限

> **重要**：157 条规则依赖特定事件类型，不同适配器发射的事件不同，实际可触发诊断种类各不一样。

| 适配器 | 诊断上限 | 说明 |
|--------|:--------:|------|
| **langchain** | 100 | 无 platform_snapshot（12 条） |
| **hermes** | 89 | 无 memory_retrieve（17 条） |
| **opencode** | 61 | 无 memory_retrieve + platform_snapshot |
| **openclaw** | 65 | 无 memory_retrieve + platform_snapshot |
| **tusunsun** | 75 | 30 条土行孙专属规则 |
| **autogpt** | 14 | 仅 agent_step + llm_invoke |
| **crewai** | 38 | 无 tool_call + memory_retrieve |
| **vercel** | 13 | 仅 llm_invoke + llm_output |

> 标注"推测"的适配器尚未本地验证，数值由事件类型推导。

## 五、核心探针运行时

| 文件 | 语言 | 说明 |
|------|------|------|
| `probe_uni.py` | Python | Python 核心探针，所有 Python 适配器的基础 |
| `probe_node.js` | JavaScript | JS 核心探针，所有 JS 适配器依赖它 |
| `probe_go.go` | Go | Go 核心探针，提供 Emit() 和 Wrap |

**适配器无上限**：每新增一个框架即新增一个生态节点。
