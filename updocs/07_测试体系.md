### 4.2 代码缺陷修复（10 个真阳性）

| 缺陷 | 影响 | 修复文件 |
|------|------|----------|
| watchdog _restart_attempts 不重置 | 自动重启永久失效 | `watchdog.py` |
| ming.py cluster 无监控循环 | 集群模式零自愈 | `ming.py` |
| cluster_archiver staging 孤儿 | 目录无限增长 | `cluster_archiver.py` |
| archiver ROLLBACK 遮蔽异常 | 原始异常丢失 | `archiver.py` |
| WAL/SHM 损坏无检测 | 数据不一致 | `archiver_schema.py` |
| ctypes.CDLL 重复创建 | 性能损耗 | `archiver.py` |
| log_error 吞异常 | 故障排查困难 | `archiver_util.py` |
| Config 注释剥离破坏字符串 | 配置解析错误 | `config_loader.py` |
| VACUUM 无磁盘检查 | 磁盘耗尽风险 | `archiver_util.py` |
| 迁移文件名解析 crash | 启动失败 | `migrations/migrate.py` |
